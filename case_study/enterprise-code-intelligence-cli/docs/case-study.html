Enterprise Code Intelligence CLI

A compact engineering study in turning enterprise source code into structured, reviewable documentation artifacts for onboarding, modernization, and operational clarity.

ProblemEnterprise codebases become hard to reason about when APIs, functions, jobs, and services evolve without a living inventory.
ApproachScan source code, normalize metadata into a stable model, and export that model into JSON, Markdown, CSV, and HTML.
OutcomeA reviewable documentation pipeline that demonstrates architecture discipline, practical tooling, and maintainable system boundaries.

Architecture

Source Code → Scanner → Inventory Model → Exporters → Documentation Artifacts

Distinguished-engineer notes

The important decision is not the scanner implementation. The important decision is the boundary around the inventory model. Once that model is stable, the scanner can become more sophisticated without disrupting downstream consumers.

Evaluation criteria

CriterionReason
Deterministic outputGenerated docs must be diffable and suitable for review.
Portable metadataJSON should be usable by other tools, not just this CLI.
Graceful degradationLegacy enterprise code is inconsistent; the tool should still return partial value.

This repository is intentionally compact and sanitized. It demonstrates the engineering pattern without exposing proprietary implementation details.
